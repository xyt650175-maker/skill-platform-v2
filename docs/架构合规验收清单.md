# 架构合规验收清单

本副本以《工程架构与编码规范》为准。上线前由平台、运维和安全团队共同验收。

- [x] Vue 3、Pinia、Vue Router、Axios、Element Plus、Vite、TypeScript 技术栈。
- [x] Spring Boot + Controller / Service / Logic / DAO + MyBatis-Plus + XML。
- [x] Git 写入统一由 `GitService` 管理；暂存遵循 update 后 add。
- [x] 生产 Git 仓库级 Redis 锁，键格式 `git:repo:{repoHash}`，30 秒 TTL。
- [x] 定版 Tag 为 `{skill-name}-{x.y.z}`；定版写入 SKILL.md 并生成 NAS ZIP。
- [x] 本地与生产环境配置隔离；生产目标为 TDSQL、Redis、NAS。
- [x] 前后端 K8s Deployment、Service、ConfigMap 和 Secret 样例。
- [x] Git 凭证使用 AES-GCM 密文保存，密钥仅经 `GIT_CREDENTIAL_ENCRYPTION_KEY` 注入；令牌不返回浏览器、不写入日志。企业 KMS/Vault 可通过同一 Secret 注入链路完成轮换。
- [x] 登录拦截器从 `team_member` 解析团队上下文，支持受控 `X-Team-Id` 切换成员团队；企业 Git 凭证查询已按 `teamId` 隔离。
- [ ] 企业 Git 远程访问：生产设置 `ENTERPRISE_GIT_BASE_URL` 且开启 `llmaif.git.verify-remote=true`；本机不允许联网，故不做远程连通性验收。
- [x] 前端已提供 ESLint、Prettier、类型检查与单测脚本；CI 必须执行 `npm run lint`、`npm run typecheck`、`npm run test:unit`。

未勾选项属于企业环境依赖，必须在接入真实 TDSQL、Redis、内部 Git 与团队身份网关后完成，不能由本地原型替代。
